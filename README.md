# 読みきかせ / Read Aloud

Your phone reads text, PDFs and web pages out loud, sentence by sentence, with the current sentence highlighted.

- Live: https://gutsmcd-cmd.github.io/read-aloud/
- Paste text, open a PDF (pdf.js is bundled, nothing is uploaded), or Share text / a link to it from another app (Web Share Target, after adding to the home screen).
- Play, pause, stop, speed, Japanese / English voice picker. Tap any sentence to read from there.
- Uses the phone's own voices (speechSynthesis), so it works offline. Free, no ads, no login.
- 日本語 / English toggle and a Large text switch.

Built with Vite + TypeScript. Deployed to the `gh-pages` branch by GitHub Actions.
